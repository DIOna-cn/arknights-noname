# 方舟 · 明日方舟主题扩展（无名杀）

这是「方舟」扩展的**发布仓库**，由发布脚本从开发目录同步生成。
玩家不需要在这里手动下载任何东西。

## 玩家怎么更新

游戏里进「**扩展 → 方舟 → 在线更新**」，点**【检查更新】**。

它会拉取本仓库根目录的 `update.json`，逐文件比对本地的大小与 MD5，
**只下载改动过的文件**，全部校验通过后才会备份旧文件并覆盖，最后自动刷新界面。
旁边还有个【强制校验】，忽略版本号把每个文件重算一遍。

下载源按 `ghproxy.net` → `gh-proxy.com` → `ghfast.top` → `raw.githubusercontent.com`
的顺序自动回退，任何一个不通都会自动换下一个。

> 首次安装仍然需要一个完整的扩展包（或在别的机器上拷贝一份整个扩展目录）。

## 仓库里有什么

| 路径 | 说明 |
| --- | --- |
| `update.json` | **更新清单**：每个文件的路径、大小、MD5。客户端的更新器只认它 |
| `extension.js` | 扩展入口与设置项 |
| `info.json` | 扩展信息、版本号（客户端以这里的 `version` 判断有没有新版） |
| `main/` | 载入钩子（`precontent` / `content`）与在线更新模块 |
| `character/` | 武将、技能、翻译、卡牌、称号、排序、简介 |
| `image/` | 衍生卡牌图与浮泡特效贴图 |
| `skill/` | 技能语音与专用音效 |
| `*.png` / `*.jpg` | 武将立绘 |
| `说明.md` | 完整实现文档（每个技能的判定细节、踩过的坑都在里面） |

## 更新是怎么工作的

1. 客户端把 `update.json` 下到扩展目录的 `.update-tmp/` 里并解析；
2. 逐文件比对：**先比长度**，长度一样才去算 MD5；
3. 列出「新增 / 变化」的文件，问玩家要不要装；
4. 全部下载到 `.update-tmp/` 并**逐个校验 MD5**，任何一个失败就整体放弃；
5. 把要覆盖的旧文件备份到 `_backup/<时间戳>/`，然后才写正式位置；
6. 记下版本号，刷新界面。

第 4 步是**先把所有文件下完、校验通过才开始动正式文件**，
所以中途断网不会留下「一半新一半旧」的扩展。

## 注意

- 这个仓库是**生成出来**的，直接改这里的文件下次发布会被覆盖。
- 仓库里**不包含**任何压缩包。
- `main/update.js` 里内联了一份 MD5 实现，它和 Node 的 `crypto` 逐字节对拍过 ——
  因为 `game.download` **不看 HTTP 状态码**，服务器返 404 时会把错误页写进目标文件，
  哈希是唯一能发现这件事的手段。
